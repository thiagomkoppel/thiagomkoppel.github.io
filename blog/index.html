Como publicar

Fluxo simples para postar novos artigos

  1. Crie um novo arquivo na pasta blog/articles, por exemplo: flamengo-volume-sem-veneno.txt.
  2. Escreva o artigo em texto simples. Use linhas começando com #, ## ou ### para títulos.
  3. Abra blog/articles.js e adicione um novo item na lista ARTICLES.
  4. Publique no GitHub Pages. O blog vai carregar o texto automaticamente quando o leitor abrir o artigo.
