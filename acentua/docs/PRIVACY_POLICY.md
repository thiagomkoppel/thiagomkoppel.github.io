# Acentua Privacy Policy

Acentua is a Chrome extension that restores high-confidence Brazilian Portuguese accents while users type.

Acentua does not collect, sell, transmit, or share personal data.

Typed text is processed locally in the browser. The extension does not send typed content, messages, emails, form entries, or browsing activity to any server.

Acentua stores only local settings using Chrome storage, including:
- Whether the extension is enabled
- Disabled websites
- Ignored words
- Custom correction pairs
- Ambiguous suggestion preference

Acentua does not use analytics, telemetry, advertising, tracking, remote logging, user accounts, or external AI services.

Sensitive fields such as passwords, emails, URLs, payment fields, and code areas are skipped where possible.
