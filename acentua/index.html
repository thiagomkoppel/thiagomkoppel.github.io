Chrome extension for Brazilian Portuguese

Acentua restores high-confidence Brazilian Portuguese accents while you type with an English keyboard. Corrections happen locally in your browser after a word is completed.

How To Use Acentua

Install the extension in Chrome, keep it enabled for the website where you are typing, then finish a word with Space, punctuation, Enter, or Tab. If the word is safe to correct, Acentua updates it immediately.

Install it in Chrome

Add Acentua from the Chrome Web Store. After installing, reload any pages that were already open.

Type normally

Write Portuguese with your usual keyboard. For example, type Eu tambem falo portugues and finish with a space.

Review ambiguous suggestions

Ambiguous words such as esta are not changed automatically. Accept the suggestion with a click or Ctrl+., or dismiss it with Ctrl+,.

Customize when needed

Use the extension options to disable websites, add ignored words, add custom corrections, or turn ambiguous suggestions on and off.

What It Does

Acentua is intentionally conservative. It corrects words that are highly likely to need an accent and avoids automatic changes when context is required.

Local corrections

Packaged dictionaries run in the browser. No server is needed for the typing path.

Capitalization aware

Lowercase, title case, and uppercase words keep their original capitalization pattern.

Safer fields skipped

Passwords, emails, URLs, payment-style fields, code areas, and unsupported editors are left alone.

Privacy Policy

Last updated: July 16, 2026.

No data collection

Acentua does not collect, sell, transmit, or share personal data.

Local processing

Typed text is processed locally in the browser. Messages, emails, form entries, and browsing activity are not sent to a server.

Local settings only

Chrome storage is used for settings such as enabled state, disabled websites, ignored words, custom corrections, and ambiguous suggestion preference.

Acentua does not use analytics, telemetry, advertising, tracking, remote logging, user accounts, or external AI services. Sensitive fields such as passwords, emails, URLs, payment fields, and code areas are skipped where possible.

Acentua is a privacy-first Chrome extension for Brazilian Portuguese typing assistance.
